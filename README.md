
# house-party

<i> Everyone loves to show off their favorite tunes. </i>
With <b> house party </b>, everyone is the DJ! &#128293;  &#128293;
Simply create a room and have your guests vote on songs.
Using your Spotify account, the queue is dynamically updated and adds songs that reach the vote threshold.

**For devs**

Usage:

 1. Download the code/ fork the repo and cd into the house-party directory.
 2. Create a Python virtual environment and download the dependencies based on requirements.txt. If you don't know how to do this click [this link](https://stackoverflow.com/questions/41427500/creating-a-virtualenv-with-preinstalled-packages-as-in-requirements-txt).
 3. Create a node_modules directory under the 'frontend' directory by running `npm install --legacy-peer-deps`
 4. From the music_controller directory run `python .\manage.py runserver`.
 5. Open another terminal window, and from the 'frontend' directory run `npm run dev`.
